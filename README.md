# ドパオセロ

返すたびに脳汁が出るオセロ。`index.html` をブラウザで開くだけで遊べます（ビルド不要・1ファイル完結）。

## 遊び方

- 光っているマスが置ける場所。数字はそのマスで返せる枚数
- マウスを乗せると、返る石がプルプル揺れてプレビュー
- 待った / ヒント / リスタート / 強さ変更 は盤面の下

## 相手の強さ

| 名前 | 中身 |
| --- | --- |
| ザコ | ランダムに置く |
| ふつう | たくさん返せる手を選びたがる（たまにミス） |
| ガチ | 3手先まで読む。残り8マスで読み切り |
| 鬼 | 6手先まで読む。残り11マスで読み切り |
| 神 | 制限時間いっぱい深く読む。残り14マスで読み切り |

AI は Web Worker で動くので、考えている間も演出は止まりません。

## 演出

- 盤は緑、石は白黒のクラシック仕様。周りは電飾とレーザーでギラギラ
- 画面全体が BGM のキックに合わせて脈打ち、火の粉が常に舞い上がる。盤の縁には放電
- 石は隕石みたいに降ってきて、着弾で空間が歪むリングが広がる
- 置くたびに盤面全体が波打ち、返る石へ稲妻が走って、元の色の破片が飛び散る
- 毎手、返した枚数に応じたハンコ（撃・連・良・優・極・爆・覇・滅・轟・神）がドンと押される
- 1枚返すごとにスコア加算（連鎖で倍率アップ、FEVER中は×3、角ボーナス、勝利ボーナス）。強さ別のベストスコアを記録
- 置けるマスにマウスを乗せると、返る石へ予告の稲妻
- 4枚で「ナイス!!」、5枚以上で「激アツ!!」（石が回転しながら跳ねる）
- 7枚以上は暗転＋心音の「来る…!?」予告のあと、画面が白黒反転して「超激アツ!!!」＋花火
- 10枚以上で「神の一手」。石が2回転、画面いっぱいの連鎖カウンター
- 角を取ると「角ゲット!!」、形勢をひっくり返すと「逆転!!」
- テンションゲージが満タンになると「確変突入!!」で 3ターンの FEVER
- 相手に大きく返されたり角を取られると「ピンチ!!」と画面割れ
- 勝つと花火の連発、負けると画面が割れてモノクロに
- 効果音と BGM は WebAudio で生成（右上のボタンで ON / SEのみ / OFF）
- フラッシュや画面揺れが苦手なら、演出を「ひかえめ」に
