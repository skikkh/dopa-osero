# ドパオセロ

返すたびに脳汁が出るオセロ。

**遊ぶ → https://skikkh.github.io/dopa-osero/**

`index.html` をブラウザで開くだけでも遊べます（ビルド不要・1ファイル完結）。公開版は [skikkh.github.io](https://github.com/skikkh/skikkh.github.io) の `dopa-osero/` に同じファイルを置いています。

## 遊び方

- 光っているマスが置ける場所。数字はそのマスで返せる枚数
- マウスを乗せると、返る石がプルプル揺れてプレビュー
- 待った / ヒント / リスタート / 強さ変更 は盤面の下

## 相手の強さ

| 名前 | 中身 |
| --- | --- |
| ザコ | ランダムに置く |
| ふつう | たくさん返せる手を選びたがる（たまにミス） |
| ガチ | 3手先まで読む。残り8マスで読み切り |
| 鬼 | 6手先まで読む。残り11マスで読み切り |
| 神 | 制限時間いっぱい深く読む。残り14マスで読み切り |

AI は Web Worker で動くので、考えている間も演出は止まりません。

## 演出

- 盤は緑、石は白黒のクラシック仕様。周りは電飾とレーザーでギラギラ
- 画面全体が BGM のキックに合わせて脈打ち、火の粉が常に舞い上がる。盤の縁には放電
- 石は隕石みたいに降ってきて、着弾で空間が歪むリングが広がる
- 置くたびに盤面全体が波打ち、返る石へ稲妻が走って、元の色の破片が飛び散る
- 毎手、返した枚数に応じたハンコ（撃・連・良・優・極・爆・覇・滅・轟・神）がドンと押される
- 1枚返すごとにスコア加算（連鎖で倍率アップ、FEVER中は×3、角ボーナス、勝利ボーナス）。強さ別のベストスコアを記録
- 置けるマスにマウスを乗せると、返る石へ予告の稲妻
- **ドパスロット**: 自分が打つと、CPU が考えている間に盤の中央で3リールのスロットが回る。左右がそろうと「リーチ!!」。枠の色で期待度が分かり（青 < 緑 < 赤 < 虹）、虹なら確定。そろえば大当たりボーナス（7: 77,777 / 神: 333,333＋FEVER突入）
- **チャンスマス**: ときどき置けるマスのどれかが虹色に光る。そこに置くとスコア ×5、スロットの当たりやすさも上がる
- **CRITICAL**: 12% の確率で画面を斬撃が走り、スコア ×2
- **ランク**: スコアに応じてルーキー → ブロンズ → … → レジェンド → 神。上がるたびに「RANK UP!!」
- 実況が「激アツ！！」「リーチ！！」「大当たり！！」「プレミアム……」などを叫び、CPU キャラもセリフをしゃべる（下の「声」を参照）
- **弾幕**: ニコニコ風のコメント（「うおおおお」「8888」「人間やめてる」「目がぁぁぁ」…）が画面を流れる。CPU にやられると「ｗｗｗ」「南無」
- **エアホーン**: 5枚以上や角で「パーパパーー」
- **ディスコ盤面**: 空きマスが BGM のビートで光る。FEVER / RUSH 中は盤面全体がミラーボール状態
- 7枚以上で盤面がまるごと縦に一回転、10枚以上で360度スピン。デジタルなグリッチと、「脳」「汁」「ド」「パ」の文字が飛び散る
- FEVER 中は背景がワープ。2回目は「超確変」、3回目以降は「神確変」
- **ドパラッシュ**: スロットで 7 がそろうと 5ターンの RUSH（スロット当選率アップ、配当2倍）
- **PREMIUM**: ごくまれに画面が真っ暗になり音も消える。数秒の沈黙のあと「PREMIUM」が浮かび上がって +1,000,000、盤面スピン、RUSH 突入
- リザルトのスコアはカウントアップ表示
- 4枚で「ナイス!!」、5枚以上で「激アツ!!」（石が回転しながら跳ねる）
- 7枚以上は暗転＋心音の「来る…!?」予告のあと、画面が白黒反転して「超激アツ!!!」＋花火
- 10枚以上で「神の一手」。石が2回転、画面いっぱいの連鎖カウンター
- 角を取ると「角ゲット!!」、形勢をひっくり返すと「逆転!!」
- 脳汁ゲージが満タンになると「確変突入!!」で 3ターンの FEVER（スコア ×3）
- 相手に大きく返されたり角を取られると「ピンチ!!」と画面割れ
- 勝つと花火の連発、負けると画面が割れてモノクロに
- 効果音と BGM は WebAudio で生成（右上のボタンで ON / SEのみ / OFF）
- フラッシュや画面揺れが苦手なら、演出を「ひかえめ」に

## 声

- 実況と CPU キャラ5人（ザコ・ふつう・ガチ・鬼・神）の声は [Irodori-TTS](https://github.com/Aratako/Irodori-TTS)（`Aratako/Irodori-TTS-v4.1-Small`、MIT ライセンス）で生成
- 設定画面の「声」で **女の子 / 男 / なし** を切り替え（初期値は女の子のアニメ声）。選んだ方の音声ファイルだけを読み込む
- 男の声版は、鬼の一部と神のセリフが未収録（そのセリフは吹き出しだけ）
- 声はすべて説明文から作った架空の声で、実在の人物の音声は使っていません。生成音声には Irodori-TTS が付ける SilentCipher の電子透かしが入っています
- `voice-girl.js` / `voice-male.js` を `index.html` と同じ場所に置くと鳴る。無ければ声なしで動く
- 音ボタン: ON（BGM＋効果音＋声）/ SEのみ（効果音＋声）/ OFF
